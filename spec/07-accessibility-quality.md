# 07 – Accessibility & quality

- Semantic HTML (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
- Every image has an `alt` text (translated).
- Everything works with the keyboard, with visible focus outlines.
- The hamburger menu button has `aria-expanded` and `aria-controls`.
- Good color contrast (readable text).
- No horizontal scrolling on phones.
- No errors in the browser console.
