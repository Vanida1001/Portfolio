# Section: Projects – `#projects`

FR: **Projets** · EN: **Projects**

A **grid of cards**: 3 columns on desktop, 2 on tablet, 1 on phone.

## Each card

| Field | Notes |
|-------|-------|
| `image` | optional; a coloured placeholder with an icon is shown if empty |
| `title` (fr/en) | |
| `date` | e.g. "2026-10", shown as "Oct 2026" / "oct. 2026" |
| `category` | `code` or `math`, shown as a coloured tag |
| `type` | `personal` or `school`, shown as a small label ("Personal" / "Perso", "School" / "Scolaire") |
| `description` (fr/en) | 2–3 sentences |
| `link` | optional; shows a "See more" / "Voir plus" link |

## Filters

Buttons above the grid: **All / Tout** (selected by default), **Code**, **Maths**.
